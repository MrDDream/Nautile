## Nautile 0.5.7 — API keys in sync, processes sorted like htop

### 🔄 Sync
- **The AI assistant's API keys can be synced**, on the phone and the computer: under « Secrets » in What is synced, off by default and set device by device. For each provider the latest key wins, and a key removed is removed everywhere. They travel encrypted like the rest, only to the devices that sync them too, and never go into a backup.
- **What is synced redone:** on the phone, one row (« 4 of 5 ») opening a pop-up with each theme's switch; on the computer, a grid of tiles outlined in their colour.

### 💻 Computer
- **Server logos** in the search of the «＋» and in Ctrl+K, as in the hosts.
- **Processes sorted like htop:** by CPU, memory, PID or name; the same column again reverses the order.
- The hosts list no longer shows the **tags** (still found by the search).

See the [0.5.0 notes](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) for everything new in this series.

## Nautile 0.5.7 — clés API synchronisées, processus triés comme dans htop

### 🔄 Synchro
- **Les clés API de l'assistant IA peuvent être synchronisées**, sur le téléphone et l'ordinateur : sous « Secrets » dans Ce qui est synchronisé, désactivé par défaut et réglé appareil par appareil. Pour chaque fournisseur, la clé la plus récente l'emporte, et une clé retirée l'est partout. Elles voyagent chiffrées comme le reste, seulement vers les appareils qui les synchronisent aussi, et ne vont jamais dans une sauvegarde.
- **Ce qui est synchronisé refait :** sur le téléphone, une ligne (« 4 sur 5 ») qui ouvre une fenêtre avec l'interrupteur de chaque thème ; sur l'ordinateur, une grille de tuiles entourées de leur couleur.

### 💻 Ordinateur
- **Les logos des serveurs** dans la recherche du «＋» et dans Ctrl+K, comme dans les hôtes.
- **Processus triés comme dans htop :** par CPU, mémoire, PID ou nom ; la même colonne une seconde fois inverse l'ordre.
- La liste des hôtes n'affiche plus les **tags** (toujours trouvés par la recherche).

Voir les [notes de la 0.5.0](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) pour toutes les nouveautés de cette série.
