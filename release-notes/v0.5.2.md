## Nautile 0.5.2 — host names no longer cut off

- **Host list (Android):** a host's name now uses the full width of its row. The last connection moves under the address in a short form (« 22 min », « 3 h », « yesterday »), and when room runs out the user name is shortened, never the IP or host name.
- **Desktop:** the Wi-Fi sync handles a peer that closes the connection more reliably on macOS, and opening the encrypted database no longer fails when two openings happen at the same time.

See the [0.5.0 notes](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) for everything new in this series.

## Nautile 0.5.2 — les noms d'hôtes ne sont plus coupés

- **Liste d'hôtes (Android) :** le nom d'un hôte prend toute la largeur de sa ligne. La dernière connexion passe sous l'adresse, au format court (« 22 min », « 3 h », « hier »), et quand la place manque c'est l'identifiant qui se raccourcit, jamais l'IP ou le nom de la machine.
- **Ordinateur :** la synchro Wi-Fi gère mieux, sur macOS, un appareil qui ferme la connexion, et l'ouverture de la base chiffrée n'échoue plus quand deux ouvertures arrivent en même temps.

Voir les [notes de la 0.5.0](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) pour toutes les nouveautés de cette série.
