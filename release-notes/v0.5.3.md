## Nautile 0.5.3 — multi-select in SFTP

- **SFTP (Android):** long-press a file or folder to select it, then tap others to add or remove them. The bar at the top selects everything, downloads the selected files into a folder of your phone, or deletes them; its menu copies them to another host or changes their permissions. With a single item selected, it also renames or edits it.
- If one item cannot be deleted or changed, the others still are, and the message says how many went through. Download and copy to another host take files only: selected folders are skipped, and the message says so.
- **Upload** now takes several files at once.
- Nothing changes on the desktop app (same version number as the phone).

See the [0.5.0 notes](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) for everything new in this series.

## Nautile 0.5.3 — multi-sélection dans le SFTP

- **SFTP (Android) :** un appui long sélectionne un fichier ou un dossier, puis chaque toucher en ajoute ou en retire. La barre du haut sélectionne tout, télécharge les fichiers choisis dans un dossier du téléphone, ou les supprime ; son menu les copie vers un autre hôte ou change leurs permissions. Avec un seul élément, elle permet aussi de le renommer ou de le modifier.
- Si un élément ne peut pas être supprimé ou modifié, les autres le sont quand même, et le message indique combien ont réussi. Le téléchargement et la copie vers un autre hôte ne prennent que les fichiers : les dossiers sélectionnés sont ignorés, et le message le signale.
- **Envoyer** accepte maintenant plusieurs fichiers d'un coup.
- Rien ne change sur l'app pour ordinateur (même numéro de version que le téléphone).

Voir les [notes de la 0.5.0](https://github.com/MrDDream/Nautile/releases/tag/v0.5.0) pour toutes les nouveautés de cette série.
